# 🍽️ Malikome Flask Restaurantes
Aplicación web desarrollada con **Python y Flask** que muestra una lista de restaurantes cercanos junto con sus horarios, imágenes y algunos de sus platillos disponibles.

Este proyecto fue creado como práctica de desarrollo web backend utilizando **Flask**, plantillas HTML y archivos estáticos como CSS e imágenes.

---

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio

```
git clone https://github.com/AlejandroRamirez31/flask-restaurantes.git
```

2. Entrar a la carpeta del proyecto

```
cd flask-restaurantes
```

3. Crear entorno virtual (opcional pero recomendado)

```
python -m venv venv
```

4. Activar el entorno virtual

Windows:

```
venv\Scripts\activate
```

5. Instalar dependencias

```
pip install flask
```

6. Ejecutar la aplicación

```
python app.py
```

7. Abrir en el navegador

```
http://127.0.0.1:5000
```

```

```


3. Create a virtual environment (optional but recommended)


```
venv\Scripts\activate
```
